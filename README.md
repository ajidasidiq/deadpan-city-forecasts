A single deadpan weather forecast for a city that does not exist, written for make.fun's "Deadpan Forecasts for Cities That Do Not Exist" bounty.

## The forecast

> In Vexford, 63 millimetres of rain fell today, all of it on one man. He has asked not to be named, and the forecast agrees.

## Run it

```sh
node main.ts
```

This writes the forecast to `/output/entry.txt`.
